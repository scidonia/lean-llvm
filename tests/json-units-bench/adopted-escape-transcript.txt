Reconstructing the old column (the measured text is pinned by digest)
---------------------------------------------------------------------
The recipe below was executed verbatim; it reproduced both the object sha256 above and the
measured rows.  It replaces the prototype's `fe_escaped` definition with the vendored
`s1f_escaped` body, renamed.  The source path is part of the object's metadata, hence
`/tmp/bench-oldesc.c`.

  python3 - <<'EOF'
  fe = open('tests/json-units-bench/bench-fastesc.c').read()
  h  = open('kernel/json/measured/s1fuse.h').read()
  body = h[h.index('static inline uint64_t s1f_escaped('):]
  body = body[:body.index('\n}\n') + 3].replace('s1f_escaped', 'fe_escaped')
  out = fe[:fe.index('static inline uint64_t fe_escaped(')] + body
  out += fe[fe.index('/* Block masks:'):]
  open('/tmp/bench-oldesc.c', 'w').write(out)
  EOF
  clang -O3 -march=x86-64-v3 -mpclmul -std=gnu11 -falign-loops=64 -falign-functions=64 \
      -I kernel/json -c /tmp/bench-oldesc.c -o /tmp/old-fastesc.o
  clang -O2 -std=gnu11 -o /tmp/bench-old tests/json-units-bench/bench.c \
      tests/json-units-bench/build/bin/s1_block.o tests/json-units-bench/build/bin/entry.o \
      tests/json-units-bench/build/bin/utf8.o tests/json-units-bench/build/bin/ablate.o \
      /tmp/old-fastesc.o tests/json-units-bench/build/bin/inline.o
